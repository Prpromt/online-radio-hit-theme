ВСТРАИВАЕМЫЙ ПЛЕЕР — ОНЛАЙН РАДИО ХИТ

Страница плеера:
/embed/

Для размещения на другом сайте:
<iframe src="https://ВАШ-ДОМЕН/embed/" width="100%" height="250" frameborder="0" allow="autoplay" title="Онлайн Радио Хит"></iframe>

Плеер использует собственный интерфейс Онлайн Радио Хит и собственный HTML5 audio-элемент. Внешние Яндекс/другие плееры в интерфейсе не отображаются.

CLOUDflare Preview:
- /embed/ — демонстрационная версия с тестовым /assets/demo.wav;
- список и обложки демонстрационные;
- внешний вид и адаптивность проверяются отдельно от production WordPress.

PRODUCTION WORDPRESS:
- создаётся страница с slug embed;
- шаблон page-embed.php получает текущую песню из WordPress;
- отображаются реальная обложка, название и артист;
- воспроизведение идёт через собственный audio-элемент сайта;
- код iframe остаётся тем же и не требует стороннего плеера.

Важно: текущая архитектура проекта передаёт в плеер URL аудиофайла текущей песни. Непрерывный единый radio-stream URL пока не подменяется вымышленным адресом и будет подключён отдельным этапом после появления рабочего production stream.
