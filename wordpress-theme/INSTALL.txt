ОНЛАЙН РАДИО ХИТ — ТЕМА v32 CLEAN

ВАЖНО: ЭТО ТЕМА, НЕ ПЛАГИН.

Установка:
1. WordPress → Внешний вид → Темы.
2. Добавить новую → Загрузить тему.
3. Выбрать ZIP этого пакета.
4. Установить.
5. Активировать.

После активации установите отдельный плагин «Онлайн Радио ХИТ — Управление v1».
Он создаёт разделы управления артистами, песнями, продвижением и заявками.

Тема не содержит фронтенд-костылей для подстановки изображений и не создаёт .htaccess.

ВСТРАИВАЕМЫЙ ПЛЕЕР — BATCH 10

В теме добавлен шаблон страницы «Онлайн Радио Хит — Embed Player».
Он использует тот же собственный HTML5 audio-плеер сайта, показывает текущую песню, артиста и обложку и не выводит Яндекс.Плеер или другой внешний плеер.

Чтобы включить production-адрес:
1. WordPress → Страницы → Добавить новую.
2. Заголовок: «Онлайн Радио Хит — Плеер».
3. Ярлык (slug): embed.
4. Опубликовать страницу.

После публикации адрес встраиваемого плеера будет:
https://ВАШ-ДОМЕН/embed/

Код для обычного сайта:
<iframe src="https://ВАШ-ДОМЕН/embed/" width="100%" height="250" frameborder="0" allow="autoplay" title="Онлайн Радио Хит"></iframe>

Важно: iframe-код вставляется на сайт владельца. Само воспроизведение выполняется нашим HTML5 audio-плеером внутри iframe; внешний музыкальный плеер не показывается.

Cloudflare Preview содержит отдельную демонстрационную страницу /embed/ с тестовым audio-файлом. Production-страница WordPress /embed/ получает реальную текущую песню из каталога WordPress.
