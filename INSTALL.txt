ОНЛАЙН РАДИО ХИТ — ТЕМА v32 CLEAN

ВАЖНО: ЭТО ТЕМА, НЕ ПЛАГИН.

Установка:
1. WordPress → Внешний вид → Темы.
2. Добавить новую → Загрузить тему.
3. Выбрать ZIP этого пакета.
4. Установить.
5. Активировать.

После активации установите отдельный плагин «Онлайн Радио ХИТ — Управление v1».
Он создаёт разделы управления артистами, песнями, продвижением и заявками.

Тема не содержит фронтенд-костылей для подстановки изображений и не создаёт .htaccess.
